## Issues found and fixed

### Docker web path crash

Error:

```text
IndexError: 3
WEB = Path(__file__).resolve().parents[3] / "web"
```

Cause: local and Docker filesystem depths differ.

Fix: web path now checks both container and repository layouts. Docker image now copies `web/`.

### Favicon 404

Added `web/favicon.svg` and `/favicon.ico` compatibility route.

### RAG false no-context result

`all-minilm` produced useful scores below the original `0.75` threshold. Default `RAG_MIN_SCORE` changed to `0.45` after live testing.

### Ollama Docker connectivity

Docker API needs host Ollama exposed beyond loopback:

```sh
OLLAMA_HOST=0.0.0.0:11434 ollama serve
```

## Optimization notes

- Keep personal, work, and project memories in separate namespaces.
- Use tags for filtering and lower-noise recall.
- Keep chunks focused; avoid indexing large unrelated documents as one memory.
- Keep SQLite as source of truth and Qdrant as rebuildable index.
- Replace the current O(n²) connection fallback with Qdrant nearest-neighbor pairs for large collections.
- Use a larger embedding model when recall quality matters more than memory usage.
- Use a larger chat model when questions require deeper reasoning.
- Add live-service integration tests to CI.
